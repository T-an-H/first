# Excel 导入模板说明

统一模板位于 `outputs/excel-import-templates-20260813/`。其中 `00-Excel导入模板合集.xlsx` 用于总览和归档；实际导入时请使用同目录下对应的单独模板，因为系统只读取文件的第一个工作表。根目录已有的旧模板没有删除或覆盖。

## 通用规则

- 系统只读取 Excel 的第一个工作表，请不要把待导入数据放在后续工作表。
- 第一行必须保留为列名；可以删除示例行后再填写真实数据。
- 学号、手机号等标识字段应按文本填写，避免前导零丢失或显示为科学计数法。
- 日期建议使用 `yyyy-mm-dd`，时间段建议使用 `HH:mm-HH:mm`。
- 深绿色列为必填列，灰色列为可选列。部分入口允许多个字段二选一，详见下表。
- 一行表示一条记录。排课时，同一门课程的不同教师、班级、日期或时间段应分别填写一行。

## 字段说明

### 学院导入

- `学院名称`：必填。兼容列名 `院系`、`系`、`name`。
- `颜色`：可选。使用十六进制颜色，例如 `#3b82f6`；不填则系统自动分配。

### 学院课程导入

- `课程名称`：必填。兼容 `课程`、`title`。
- `课程分类`：必填。必须是当前学院中已存在的分类名称；也可以改用 `分类ID` 列填写分类 ID。
- `教师`、`课程描述`、`学分`、`课时`：可选。
- `状态`：包含“结束”时导入为已结束，其他值导入为进行中。

### 课程排课导入

- `日期`、`时间段`：必填。
- `结束日期`：可选，不填时与日期相同。
- `课程名称`：可选，不填时使用管理员当前选中的课程。
- `教师`、`企业导师`、`班级`、`教室`、`周几`：可选，但建议按实际排课完整填写。
- 同一门课程可以有多名教师和多个班级，每个“教师 + 班级 + 日期 + 时间段”组合单独占一行。

### 班级成员与课程学生

- `04-新增班级成员导入模板.xlsx` 按列名识别，可填写学生姓名、学生学号中的任意一项。
- `05-课程学生导入模板.xlsx` 按列位置识别，不要调换两列顺序。找不到的学生会按导入信息创建，再加入当前课程。

### 分组导入

- `06-课程分组导入模板.xlsx` 用于当前课程详情页。第 1 列固定为组名，第 2 列及之后每个单元格填写一名学生姓名或学号。
- 从某个班级内发起导入时，只会接收该班级的学生。
- `11-旧版课程分组导入模板.xlsx` 仅用于旧课程管理入口；同组成员集中填写在 `成员姓名` 一格内，用中文逗号、英文逗号、顿号或空格分隔。

### 成绩导入

- 推荐使用 `学生姓名 | 学生学号 | 班级 | 成绩` 四列格式。
- 也兼容简化的两列格式：第 1 列学生姓名或学号，第 2 列成绩。
- 从页面下载的成绩模板会把当前考试名称作为最后一列列名，导入时会自动识别该列。
- 成绩会被限制在 0 到 100 之间；无法匹配到数据库学生的行会被跳过。

## 旧入口说明

`08` 至 `11` 对应 `src/pages/teacher/Courses.vue` 中仍然存在的旧课程管理导入入口。它们与课程详情页的新版入口格式不同，因此单独保留模板，避免混用。
